\noindent\textbf{Spoken Script:}
\begin{quote}
\textit{``Namaste! In India, millions of intercity bus seats go to waste every week. When a traveller's plans change close to departure, cancellation charges hit 100\%---a complete loss of their fare. At the exact same minute, another passenger searching that identical route sees `Sold Out'.}

\textit{Why can't travellers just give their ticket to someone else? Because tickets carry government photo IDs! Open ticket reselling fails: buyers get turned away at boarding, tickets get fraudulently sold twice, or scalpers inflate prices.}

\textit{Introducing \textbf{SeatRelay}: India's first operator-authorized bus seat resale protocol. We enable confirmed tickets to change hands at \textbf{exact face value} up to departure, with zero scalping, cryptographic identity verification, and authentic manifest reissuance directly on the operator's official manifest.''}
\end{quote}

\subsection*{Part 3: Tech Stack \& AWS Cloud Architecture (1:30 -- 2:20)}

\begin{visualcue}
Open the \textbf{AWS Reference Architecture Modal} or highlight the architecture block diagram showing Step Functions, DynamoDB, EventBridge, Lambda, Cognito, and S3.
\end{visualcue}

\noindent\textbf{Spoken Script:}
\begin{quote}
\textit{``Under the hood, SeatRelay is built on an enterprise-grade AWS Serverless architecture designed for zero data loss and massive holiday demand spikes:''}

\begin{itemize}[noitemsep,topsep=2pt]
    \item \textbf{AWS Amplify Hosting \& Amazon Cognito:} Powers our responsive React, TypeScript, and Tailwind frontend with role-based access control for travellers and fleet operators.
    \item \textbf{Amazon API Gateway \& AWS Lambda:} RESTful serverless microservices executing atomic listing, search, and settlement validations.
    \item \textbf{Amazon DynamoDB Atomic One-Buyer Guarantee:} Built using conditional expressions (\texttt{attribute\_exists(listingId) AND status = 'LISTED'}). When 50 buyers tap Claim in the same millisecond on a festival weekend, DynamoDB guarantees strictly \textbf{one} write succeeds. The other 49 receive a clean 409 Conflict with zero accidental charges.
    \item \textbf{AWS Step Functions Centerpiece:} Coordinates the transfer state machine. It enforces the 10-minute checkout window, pauses on a task token awaiting operator approval, and orchestrates atomic rollbacks if declined.
    \item \textbf{Amazon EventBridge Scheduler:} Spawns precision one-shot timers per listing, auto-expiring unsold seats at $T-60$ minutes so the seller retains standard operator cancellation rights.
    \item \textbf{Amazon S3 \& SNS:} Manages encrypted QR boarding passes and distributes real-time SMS/email alerts at every state transition.
\end{itemize}
\end{quote}
